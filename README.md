# PlanetMC — /assets/img/

Place your image files here:

| File               | Usage                                        | Recommended size |
|--------------------|----------------------------------------------|-----------------|
| logo.png           | Site logo (nav, hero, footer, favicon)       | 512×512 px      |
| banner.png         | Social preview (OG / Twitter card)           | 1200×630 px     |
| banner-social.png  | Alternative social banner                    | 1200×630 px     |

## Subfolders

- /icons/      — Additional icon assets
- /background/ — Background texture or pattern assets

## Notes

- logo.png replaces the old /logo.png at root.
- banner.png replaces the old /assets/img/banner.png.
- All paths in HTML/CSS already point to /assets/img/.
